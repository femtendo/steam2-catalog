What this site is

A research and preservation catalog of the metadata of a publicly mirrored archive of Valve's legacy Steam2 content-delivery servers. We publish facts about the archive: depot identifiers, file names, sizes, dates, and cryptographic hashes. We do not host, distribute, or extract game content.

By using this site you agree that

  • The catalog is provided as is, with no warranty of accuracy or completeness. Verify anything that matters against the primary sources before relying on it.
  • You will not use the catalog to infringe others' rights. Game content remains the property of its respective owners; download links point to third-party mirrors that this project does not operate.
  • Content extracted from the archive is 2003–2013 software that was never quality-controlled. If you run it — in a virtual machine, as we recommend — you do so entirely at your own risk. The authors are not liable for any damage or data loss.
  • You will not use automated access in a way that harms the community mirrors (aggressive scraping, excessive parallel downloads of payloads).

Content and takedowns

Indexing metadata (file names, hashes, sizes) is factual data. We do not host copyrighted game files. If you are a rights holder and believe specific content should be removed from the catalog's documentation, open an issue on the project tracker or contact the maintainer through it; we respond to good-faith takedown requests promptly.
